# GAMEHUB

Статический каталог игр для GitHub Pages: HTML + CSS + JavaScript.

## Что работает
- каталог и демонстрационные игры;
- поиск и фильтры;
- регистрация, вход, выход и гостевой режим;
- показ/скрытие пароля;
- 10-секундный JS-таймер перед скачиванием;
- переход по внешней ссылке файла;
- demo-админка с добавлением, редактированием и удалением игр;
- рекламный HTML-блок;
- статистика игр, локальных пользователей и скачиваний.

## Важное ограничение
GitHub Pages — статический хостинг. Здесь нет настоящего backend, базы данных, безопасной server-side авторизации или защищённой роли администратора. Демо-версия использует `localStorage`, поэтому не храните реальные пароли и не считайте эти аккаунты безопасными. Данные не синхронизируются между браузерами и исчезают после очистки данных сайта.

Для production-нужны backend/API, база данных, безопасное хеширование паролей и серверная авторизация. Это намеренно не включено, так как проект должен оставаться полностью статическим.

## Demo admin
Войдите/зарегистрируйтесь с username `admin`, затем откройте `admin.html`. Это локальная демонстрационная логика, не настоящая безопасность.

## GitHub Pages
1. Создайте новый GitHub repository.
2. Загрузите содержимое этой папки в корень репозитория.
3. `Settings → Pages`.
4. `Deploy from a branch`.
5. Выберите `main` и `/ (root)`.
6. `Save`.
7. Откройте выданную GitHub Pages ссылку.

Обычно URL имеет вид `https://USERNAME.github.io/GameHub/`.

## Файлы игр
В админке указывайте прямую внешнюю ссылку, например `https://example.com/game.apk`. Сами большие файлы в GitHub не хранятся.
